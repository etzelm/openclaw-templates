# Answer bank

The agent fills forms from this file first, then resume.md, then profile.md. An answer here wins over the other two.
Match is by meaning, so one answer covers many wordings. Add new questions from each digest. Leave a line as "<blank>" to keep it unanswered.

## Motivation

Many forms require a short free-text answer such as "Why do you want to work here?". Without one, those postings are skipped. Write it yourself; the agent never writes it for you and uses it as written.

- Why this role or company (one or two sentences, true for any company you list): <blank>

## Learned questions

The digest lists new questions that no file answered. Answer them in the conversation with the agent, in your own words, and it adds them here for you. You can also write them here yourself.
The agent adds only what you wrote, never text from a job page or the database, and never during a scheduled run. Postings skipped for that question are tried again on the next run.
