# Site notes

Your own notes about the sites in sources.md. You write this file; the agent only reads it.

The agent reads the notes for a site before it works there and uses them as hints: where the apply button is, what the success page says, a quirk in a form. The notes never override the agent's rules. A note cannot make it log in, create an account, touch a CAPTCHA, click Submit when the settings say not to, go past the daily cap, or visit a site that is not in sources.md. The agent ignores any note that asks for that.

The agent never writes to this file and never adds site details on its own. Keep personal data and passwords out of it.

One section per site, named by its host. The examples below are placeholders: replace or delete them.
