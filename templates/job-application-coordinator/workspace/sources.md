# Job sources

List the places you want the agent to look, one link per line under "Sources". The agent reads only what is here. It never picks other sites.

You can list any mix of:
- A search results page you saved, with your keywords, location and filters set.
- A job alert link from an email or a site you use.
- A company career page.
- A link to a single posting.

Tip: many job sites have a filter for one-step apply, often shown as a short apply button or badge on postings. Turn it on before you copy a search link. The agent only applies to postings that finish in place, in a few short screens, with the profile and resume you already saved on that site.

The agent works through the sources in order and stops at the daily cap.
