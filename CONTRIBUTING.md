# Contributing

Thanks for helping.

- Report bugs with the GitHub issue form. Name the Template, its version and your OpenClaw version.
- Keep a change to one Template per pull request.
- Run `openclaw templates validate` on the Template folder and run its tests before you open a pull request.
- Add a line to the Template's `CHANGELOG.md` under a new version.
- Write plain, short sentences. No em dashes.
- Never put tokens, keys, personal paths or personal data in a file, a test or a commit message.

By contributing you agree that your work is released under the MIT license in [LICENSE](LICENSE).
